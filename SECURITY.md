# Security policy

## Supported versions

graphraum is pre-1.0. Security fixes land on `main` and ship in the next release; use the latest version from npm.

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub security advisories](https://github.com/yggy-tech/graphraum/security/advisories/new), not in a public issue or pull request.

Include what is affected, how to reproduce it and the impact you see. We confirm receipt within three working days and keep you informed until a fix is released. We credit reporters in the advisory unless you ask us not to.
