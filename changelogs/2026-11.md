# November 2026

## 2026-11-06

- Force layouts have a second style for graphs that end up as one tangled ball. Set `repulsionModel: "edge-t"` in `ForceSettings` to give well-connected nodes more room, so groups separate and hubs no longer pile up in the middle. It works for `computeForcePositions()`, clustered layouts and `createForceSimulation()`, and a running simulation can switch with `setSettings()` without starting over. `"classic"` stays the default ([#191](https://github.com/yggy-tech/graphraum/issues/191)).
